# 鋼魂戰線 Iron Front

像《雷霆任務》（Front Mission）那樣的機甲戰略模擬（SLG）：自己組裝機甲（機身、左右手臂、腿部、手上和肩上的武器），在斜角視野、有高低差的戰場上指揮小隊作戰。故事、角色和機體都是原創的。中文和英文都有。

A wanzer tactics game in the spirit of Front Mission: build each machine from a body, two arms, legs and weapons, and lead the squad across isometric battlefields with hills and buildings. Original story, characters and machines. Chinese and English.

**線上玩：** https://ywchen0711.github.io/ironfront/

## 美術

照超任時代的雷霆任務畫風：所有東西都先畫在低解析度的畫布上，再整數倍放大、不做平滑，每一點都是清楚的方塊。顏色用鏽紅、水泥灰、橄欖綠和鋼鐵灰這類暗沉的色調；地面是有斑駁雜點的水泥、柏油（褪色的黃線）、草地、雪地，地上有油漬、人孔蓋、木箱、電線桿、殘骸；倉庫是波浪鐵皮屋頂加直條紋牆面，會在旁邊的地上投下影子。機甲是一節一節的關節機體（我方橄欖綠、敵方鋼灰配橘色）：髖關節、大腿（液壓桿）、護膝、小腿裝甲、腳掌，方盒軀幹上有座艙玻璃、胸甲、散熱口和鉚釘，兩側有大肩甲，頭部有護目鏡和會閃的眼睛。比例矮壯：短腿、寬厚的軀幹、大肩甲、小頭。每一格畫面都用自己寫的像素繪製器重新畫，不用黑色外框，改用像素畫的寫實打光：每種材質七階色（暗部偏冷、亮部偏暖），圓的部件照圓柱打光並帶反光點，平板依朝向打光、受光的邊比較亮，部件交疊處有接觸陰影，戰鬥畫面的大圖用有序抖色（dithering）做漸層；走路時雙腿交替跨步、膝蓋彎曲、著地的腳不會滑，身體上下起伏、手臂反向擺動；站著會輕微呼吸起伏；開火時手臂舉起瞄準、有後座力和槍口火光；被打中會晃動。介面是橄欖灰的立體框、黑色長條的 BODY／ARM／LEGS 耐久表和像素字體，開火時機體頭上會跳出「Fire」。戰鬥畫面有工廠剪影的黃昏背景、更大更細的側面機甲、像素曳光彈、飛彈煙霧和爆炸。

## 玩法

- **部位破壞**：每架機體的機身、左臂、右臂、腿部各有耐久度。打壞手臂，那隻手上的武器就不能用；打壞腿部，移動力只剩 1、也不能閃避；打壞機身才算擊毀。
- **武器**：機槍、霰彈槍、步槍、狙擊步槍（射擊）；電磁棍、衝擊拳套、重斧（格鬥）；火箭、飛彈（肩上，有彈藥數）；盾牌可以減少傷害。手臂還在就能用拳頭。
- **反擊**：被攻擊的一方會用「同一類」的武器反擊——用格鬥打人，對方就用格鬥打回來；用飛彈從遠處打，大多數敵人就沒辦法反擊。
- **地形**：森林、高地、瓦礫好躲；從高處往下打比較準；建築和牆擋路；雪地和森林走得慢；水只有氣墊腿過得去。
- **戰鬥畫面**：每次開火都會切到側面的戰鬥動畫，顯示每一發打到哪個部位、打掉多少（可以關掉）。
- **修理**：每架機體每場任務可以修理兩次。
- **基地**：任務之間在機庫換零件和武器（機身的出力要撐得住全部重量），在商店買賣。駕駛員會升級，命中和閃避會提升。

## 六場任務

邊境哨站 → 南岸港口 → 黑木森林（擊毀韋特少校）→ 霜嶺補給線 → 舊城區 → 北方要塞（擊毀黑犬）。途中狙擊手莉娜和重裝兵杜克會加入。

## 檔案

- `js/data.js`：零件、武器、地形、駕駛員、任務地圖和劇情（中英文）
- `js/rules.js`：組裝、移動範圍、命中率、部位傷害、反擊、修理、升級
- `js/ai.js`：敵人的判斷（每個可到的格子、每把武器、每個目標算出預期傷害和會受到的反擊）
- `js/render.js`：像素畫：每一格地形的貼圖、倉庫、樹、道具、戰鬥畫面
- `js/mech.js`：機甲的骨架、姿勢（走路、瞄準、後座力、受擊）和像素繪製
- `js/main.js`：畫面、操作、基地、存檔
- `tools/test.mjs`：`node tools/test.mjs` 檢查地圖和資料，並讓電腦兩邊對打每一關各 20 次
